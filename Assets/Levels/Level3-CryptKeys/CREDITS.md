# Crypt Keys — Credits

Every picture, sound and font in Crypt Keys comes from a free pack, and every pack is
**CC0** (public domain): free to use, change and share, in any project, with no
attribution needed. We credit them anyway. Only the files the game uses are in `Art/` and
`Audio/`; each pack's licence is beside them.

The files were renamed on the way in, so every sheet follows one pattern,
`<Character><Direction><Animation>.png` (for example `SkeletonLeftWalk.png`). The packs'
own names have typos (`SkeletonWithBowLefttIdle`) and call the skeletons' side walks `Run`.
The mimic and the spikes are for the Challenges: the game itself doesn't use them.
