# Gate Guard — Credits

Every model, clip, picture, sound and font in Gate Guard comes from a free pack. All but
two are **CC0** (public domain): free to use, change and share, in any project, with no
attribution needed. We credit them anyway. The icons are **CC BY 3.0**, which asks for
credit, and the font is under the **SIL Open Font License**. Only the files the game uses
are in `Art/` and `Audio/`; each pack's licence is beside them.
